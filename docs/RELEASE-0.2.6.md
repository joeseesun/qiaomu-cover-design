# Qiaomu Design 0.2.6

- 添加排版和生图模型支持全选当前搜索结果、清空选择；始终显示已选数量，并提示被搜索隐藏的已选项。
- 相同连接下的已有模型标记为“已添加”，手动填写也不会重复添加或覆盖别名。
- 新增模型保留已有默认模型及参数；首次配置才使用第一个选中项作为默认。
- 长列表支持“显示更多”；超过模型容量时明确提示，不会悄悄截取部分选择。搜索、刷新、返回和保存失败均保留选择。

验证：lint/typecheck/build、124 项自动测试；macOS Obsidian 1.14.4 的真实多选、跨搜索、默认模型、失败回退、中英文与窄屏验收。未重新执行第三方 OAuth 授权或付费生成；未验证 Windows/Linux。
