# 设计原则（写进 AI 设计师提示词的依据）

AI 设计师的版面决策遵循下面几条。它们既写在 `src/ai.ts` 的系统提示里，也有一部分被固化为代码，不依赖模型发挥。

| 原则 | 依据 | 在产品里的落实 |
| --- | --- | --- |
| 一个焦点，层级靠大小/粗细/颜色/留白的对比 | 瑞士风格；“网格只能排列，不能分主次，主次靠尺度与对比” | `fitTitle`：短标题放大至盒子上限；副标题随标题放大 |
| 亲密性：相关的东西靠近 | 版式六法则（对比/对齐/亲密/重复/留白/变化） | `tightenCopy`：宽版封面把副标题拉回标题下，整块文字光学居中 |
| 对齐到同一条线 | Müller-Brockmann 的网格 | 装饰锚定到标题末行或主体中心，不再散落 |
| 留白是设计，删掉没有用途的元素 | Müller-Brockmann；日式海报的克制 | 装饰最多 3 件，大件淡化、出血，小件克制 |
| 粗细/宽窄/颜色并置制造张力 | Paula Scher | 提示词要求字重反差；标题可用有性格的字体 |
| 一个强调色 | 通用 | 装饰只用配色角色（accent/ink/…），不写随机色值 |
| 字体有性格，全图 ≤2 种 | 字体搭配常识 | 开源字体库 + `titleFont`，按题材气质选字体 |
| 避免孤字换行 | 排版基本功 | `hasOrphan`：标题字号选择时跳过会出现孤字的尺寸 |
| 文字与主体不抢同一块像素 | 构图 | `arrangeForSubject`：竖版有主体时文字叠到上半部 |

## 灵感调研结论（2025–2026）

来源：Abduzeedo「Design Trends 2025: Systematic Grids and Typographic Tension」、Kittl 2025 设计趋势、VidIQ / CapCut 缩略图指南、人人都是产品经理《小红书爆款封面拆解》。

1. **编辑感极简取代渐变与特效**：大号衬线/粗黑标题 + 大量留白 + 不对称网格 + 斜体强调。「少说，多表达」。
2. **一个视觉钩子**：每张封面只有一个最抢眼的元素（巨型数字、一张主图、一条对比分界线）。其余让位。
3. **标题至少占画面 1/4**；缩略图文字 ≤5 个词；2–3 个视觉元素封顶。
4. **色彩克制**：主色 + 辅色 + 强调色，强调色只占 5–8%；趋势色是鼠尾草绿、陶土、灰蓝、淡紫等低饱和色，深蓝配橙是安全的高对比组合。
5. **网格与基线对齐**：所有元素贴同一条左边线或同一条基线；字重和字号拉开层级（至少 2.5 倍）。
6. **质感用纸张、颗粒，而不是黑描边和硬投影**：描边字、爆炸星、放射光、跑马灯、霓虹发光都属于「土味」信号，一律不用。
7. **深色只在内容本身是深色气质时用**，且必须有明确的单一强调色；默认浅色底。

### 渐变的位置（2026-10）
审查结论：效果差的封面多半是渐变底，效果好的是“大字 + 纯色 + 强反差”。原因：渐变把底色拉到中间调，文字反差变低；弥散渐变没有焦点，在 150 px 的信息流缩略图里只剩一团糊色；紫蓝 / 粉紫渐变是模板工具的默认配色，一眼“模板味”。
落实：
- 渐变只当光（主体背后的一点光晕、照片上的压暗），不当主题色；AI 设计师默认不写 `bg2`。
- keyword、window 改为纯色底；acid、glass、aurora、photo（无图时）排到图库最后，AI 只在用户点名“弥散 / 玻璃 / 极光”时选用。
- 套路库同步：xhs-pit 修正为白底不可读的黑字、bili-knowledge 由 bili-explainer 取代、wx-tech 改用拱门窗、x-banner 改用叠字海报，数字类配色去掉渐变。

### 从《2026 小红书 AI 封面设计》吸收的规则
来源：[tixiaolu.com](https://www.tixiaolu.com/posts/ai-xiaohongshu-cover-design-2026/)。文章整体偏工具导向，可用的部分如下：
- 标题 8~10 字最佳、≤15 字；标题文字占封面 30%~40%（案例中把文字放大到 40%，点击率从 3% 到 9%）。→ 写进 AI 设计师的 title 规则。
- 生图提示词按「主体 + 风格 + 色调 + 构图 + 细节」五段写，并为文字预留空白；负面提示：不模糊、不变形、无多余手指、无水印。→ 写进 imagePrompt 说明与 `IMAGE_RULES`。
- 账号统一：确定 2~3 套模板长期使用；同一内容做 3~5 版不同风格做 A/B。→ 待做（见下）。
- 不采纳：文中推荐的“梦幻渐变 #667EEA→#764BA2”，与上面的渐变结论冲突。

### 账号统一、A/B 与缩略图自检（已实现）
1. **我的系列**（`src/series.ts`）：模板抽屉顶部「存为系列」，保存当前版式 + 配色 + 字体，最多 6 个，同版式同配色自动去重。点一下即套用（保留文字、图片和装饰）。AI 设计师默认沿用第一个系列，内容明显是另一类时选最贴近的系列，用户说“换风格”才自由选。也可用命令「存为系列」。
2. **一键 3 版**：命令「生成 3 个版式对比（A/B）」在助手面板出 3 张缩略图，点一张直接换上。挑选规则（`pickVariants`）：先按文案挑（标题有数字 → 大数字版式，副标题是问句 → 聊天截图，有清单 → 备忘录 / 便当，短标题 → 叠字 / 大字），再保证 3 张来自不同风格族（大字 / 纸面 / 物件 / 数字），且不选渐变类。AI 出图后的“换个版式”也用同一规则，并用真实配对字体渲染。
3. **缩略图自检**（`thumbCheck`）：按各平台信息流卡片的实际宽度（小红书约 170 px、YouTube 侧栏约 168 px、公众号约 150 px）换算文字高度，标题 < 11 px、副标题 < 6 px 或标题超过约 15 字时给出提示。导出对话框里显示真实卡片宽度的预览和提示，AI 设计完成后也会附在说明里。
4. **模板总览**：`npm run gallery`，打开 http://localhost:4377/ ，总览图存到 `artifacts/template-gallery/`（见 `scripts/template-gallery/README.md`）。
