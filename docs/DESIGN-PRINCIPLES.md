# 设计原则（写进 AI 设计师提示词的依据）

AI 设计师的版面决策遵循下面几条。它们既写在 `src/ai.ts` 的系统提示里，也有一部分被固化为代码，不依赖模型发挥。

| 原则 | 依据 | 在产品里的落实 |
| --- | --- | --- |
| 一个焦点，层级靠大小/粗细/颜色/留白的对比 | 瑞士风格；“网格只能排列，不能分主次，主次靠尺度与对比” | `fitTitle`：短标题放大至盒子上限；副标题随标题放大 |
| 亲密性：相关的东西靠近 | 版式六法则（对比/对齐/亲密/重复/留白/变化） | `tightenCopy`：宽版封面把副标题拉回标题下，整块文字光学居中 |
| 对齐到同一条线 | Müller-Brockmann 的网格 | 装饰锚定到标题末行或主体中心，不再散落 |
| 留白是设计，删掉没有用途的元素 | Müller-Brockmann；日式海报的克制 | 装饰最多 3 件，大件淡化、出血，小件克制 |
| 粗细/宽窄/颜色并置制造张力 | Paula Scher | 提示词要求字重反差；标题可用有性格的字体 |
| 一个强调色 | 通用 | 装饰只用配色角色（accent/ink/…），不写随机色值 |
| 字体有性格，全图 ≤2 种 | 字体搭配常识 | 开源字体库 + `titleFont`，按题材气质选字体 |
| 避免孤字换行 | 排版基本功 | `hasOrphan`：标题字号选择时跳过会出现孤字的尺寸 |
| 文字与主体不抢同一块像素 | 构图 | `arrangeForSubject`：竖版有主体时文字叠到上半部 |

## 来源
- 瑞士风格与网格：Big Human、Envato、Swiss Themes 的整理；Josef Müller-Brockmann《Grid Systems in Graphic Design》
- Paula Scher 的字重/字距对比：Fast Company《10 Crucial Lessons From History's Greatest Graphic Designers》
- 版式六法则、留白与层级：设计达人、人人都是产品经理、知乎的海报版式文章

## 灵感调研结论（2025–2026）

来源：Abduzeedo「Design Trends 2025: Systematic Grids and Typographic Tension」、Kittl 2025 设计趋势、VidIQ / CapCut 缩略图指南、人人都是产品经理《小红书爆款封面拆解》。

1. **编辑感极简取代渐变与特效**：大号衬线/粗黑标题 + 大量留白 + 不对称网格 + 斜体强调。「少说，多表达」。
2. **一个视觉钩子**：每张封面只有一个最抢眼的元素（巨型数字、一张主图、一条对比分界线）。其余让位。
3. **标题至少占画面 1/4**；缩略图文字 ≤5 个词；2–3 个视觉元素封顶。
4. **色彩克制**：主色 + 辅色 + 强调色，强调色只占 5–8%；趋势色是鼠尾草绿、陶土、灰蓝、淡紫等低饱和色，深蓝配橙是安全的高对比组合。
5. **网格与基线对齐**：所有元素贴同一条左边线或同一条基线；字重和字号拉开层级（至少 2.5 倍）。
6. **质感用纸张、颗粒，而不是黑描边和硬投影**：描边字、爆炸星、放射光、跑马灯、霓虹发光都属于「土味」信号，一律不用。
7. **深色只在内容本身是深色气质时用**，且必须有明确的单一强调色；默认浅色底。

## 模板库（2026-10 审查与重做）

### 审查发现与处理
| 问题 | 涉及模板 | 处理 |
| --- | --- | --- |
| 中英混排标题被 Fabric 拆词（“A / I”）、第二行行首留空格、末行孤字 | folio、sage、mag、calm、split、photo、mega 等约 10 个 | `textbox` 对所有中文文本自行断行（`wrapLines`：不拆英文词、不以标点开头、末行孤字自动借字），行内空格转不换行空格，按最终字距 −18 断行，构造时就用配对字体，避免 Fabric 用后备字体把文本框撑宽 |
| 叠影字和正文断行不一致，糊成一团 | acid | 去掉叠影，改为居中大字 + 弥散光 + 一枚闪光 |
| 宽版标题压住副标题 / 红条 | number、print | 副标题改为紧贴标题下方、整块垂直居中；print 标题高度限制在标签区与红条之间 |
| 大数字与标题相撞 | numeral | 数字字号按左栏宽度计算，标题块垂直居中 |
| 描边字、爆炸星、放射光、硬投影字（违反第 6 条） | pop、bili | pop 改成无描边的平面贴纸波普；bili 改成“B 站知识区”：浅灰底、粉蓝双色、分区标签、小电视画框（屏幕即图位） |
| 副标题过小、贴底 | neo | 副标题字号 ≥ 标题 0.3，紧贴标题，整块在卡片内居中 |
| 杂志巨型虚影用了标签文字（“干货”变成怪形状） | mag | 虚影与期号只用数字 |
