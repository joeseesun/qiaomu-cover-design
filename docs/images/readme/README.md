## 真实模板输出

`templates-real.png` 来自 0.2.1 提交 `60f618f` 的模板代码、Fabric 浏览器渲染与字体文件，非生成式图片。字体来自 0.2.1 完整发行 ZIP，34 个文件逐个通过编译清单的大小与 SHA-256 校验，浏览器确认 34 个 FontFace 加载完成。三行：folio、notes、swiss；三列：xhs、youtube、wechat。输入标题为「30 天学会 AI 写作」，副标题为「从零开始的完整路线图」，角标为「干货」。

先安装 npm 依赖，将完整发行包的 `fonts/` 复制到仓库 `assets/fonts/`。如果没有 `index.json`，从当前编译清单导出索引（需要字体文件与此清单匹配）：

```sh
node --import tsx --input-type=module -e 'import { BUNDLED_FONTS } from "./src/fontmanifest.ts"; import { writeFileSync } from "node:fs"; writeFileSync("assets/fonts/index.json", JSON.stringify(BUNDLED_FONTS));'
npm run gallery
```

打开本地图库：

```text
http://localhost:4377/?sizes=xhs,youtube,wechat&only=folio,swiss,notes&out=readme&w=380&per=3
```

页面显示 Done 后，检查 `artifacts/template-gallery/readme-0.png`，将最终图片复制到此目录。模板图库是开发验证页面，不是完整 Obsidian 界面；实际发布前仍需在宿主中检查设计与导出。
