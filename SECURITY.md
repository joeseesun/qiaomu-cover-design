# 安全报告 · Security reporting

请不要在公开 Issue 中上传密钥、私人笔记、参考图片或可直接利用的敏感细节。

优先使用仓库 Security → Report a vulnerability（如该入口可用）。如果没有私密报告入口，请通过 [X @vista8](https://x.com/vista8) 请求私密联系渠道，第一条消息只说明需要报告安全问题，不附利用细节或用户数据。此文档不承诺响应时限。

报告请包含插件和 Obsidian 版本、系统、最小复现、影响范围，以及已脱敏的日志。模型端点、代理和本地 CLI 属于用户配置的信任边界；报告时区分插件行为与服务商行为。

English: do not publish credentials, private vault content or exploit details in public issues. Use GitHub's private vulnerability reporting if available; otherwise request a private channel from [@vista8](https://x.com/vista8) without sending sensitive details in the initial message. Include versions, a minimal reproduction, impact and sanitized logs. No response-time guarantee is implied.
